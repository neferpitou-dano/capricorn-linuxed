# Автообнаружение и голосовой выбор приложений

Капри проверяет локально доступные приложения и компоненты. Сканирование ничего не устанавливает и не запускает; выбор сохраняется в `config.json` → `provider_preferences`.

## Голосовые команды

- «Капри, какие программы ты нашла?» — показывает найденные браузеры, музыкальные приложения, игровые лаунчеры и ключевые компоненты.
- «Капри, используй Firefox как браузер» — выбирает браузер для открытия сайтов.
- «Капри, используй Spotify для музыки» — выбирает Spotify; можно также сказать «для музыки используй Яндекс Музыку».
- «Капри, включи музыку» — открывает ранее выбранный сервис. Если найден ровно один установленный музыкальный плеер, Капри выберет его автоматически; если вариантов несколько, спросит пользователя.
- «Капри, используй Vosk для распознавания речи» — отключает дополнительную проверку распознавания через Google (основной локальный Vosk остаётся).
- «Капри, используй Google для распознавания речи» — включает дополнительную проверку через Google, если установлен нужный пакет.
- «Капри, используй Silero для голоса» — переключает синтез на Silero при наличии PyTorch.
- «Капри, используй Edge для голоса» — переключает синтез на Edge TTS при наличии `edge-tts`.

## Границы обнаружения

Обнаружение означает, что приложение или компонент найден в системе, но не гарантирует, что аккаунт авторизован или удалённый сервис доступен. В Linux приложения ищутся через `.desktop`-файлы и `PATH`; браузеры, музыкальные приложения и игровые лаунчеры перечисляются отдельно. Яндекс Музыка и Spotify могут быть доступны как веб-сервисы даже без нативного приложения. Капри не устанавливает пакеты автоматически и не запускает произвольные команды из результата сканирования.
