# Capri — Linux-порт

## Поддерживаемые системы

Установщик рассчитан на следующие семейства дистрибутивов:

- Arch Linux, включая CachyOS и Manjaro;
- Fedora;
- Debian и Ubuntu.

Для установки доступны `install.fish` и `install.sh`, для запуска — `run.fish` и `run.sh`.

## Установка

Fish:

```fish
fish ./install.fish
fish ./run.fish
```

Bash:

```bash
./install.sh
./run.sh
```

Установщик создаёт виртуальное окружение `.venv` с доступом к системным пакетам, устанавливает зависимости из `requirements-linux.txt` и распаковывает архив модели Vosk из `bundled/`, если модель ещё не установлена.

## Особенности Wayland

Wayland ограничивает приложения в возможности читать и управлять окнами других программ и эмулировать ввод. Поэтому часть функций, доступных в Windows или X11, может работать иначе либо быть недоступна в конкретном окружении.

В Linux-порту используются системные инструменты для отдельных функций:

- `wpctl` — управление громкостью;
- `playerctl` — управление медиаплеерами;
- `.desktop`-файлы — обнаружение приложений;
- `xdg-open` — открытие ссылок и файлов;
- `wtype` — ввод текста в поддерживаемых Wayland-сеансах;
- `hyprlock` — блокировка сеанса в Hyprland.

`wtype` и `hyprlock` нужны только для соответствующих функций и не являются обязательными для базового запуска.

## Пользовательские данные

`config.json`, журналы и данные напоминаний создаются или изменяются локально. Не добавляйте их в публичный репозиторий. Файл `.gitignore` содержит соответствующие исключения.
