# Capri

Capri — голосовой помощник с распознаванием русской речи, экранным аватаром, голосовыми командами и настраиваемыми интеграциями.

Проект содержит Linux-порт. Поддержка отдельных системных действий зависит от дистрибутива, рабочего стола и доступных системных инструментов. В частности, Wayland ограничивает управление чужими окнами и вводом по сравнению с Windows.

## Возможности

- Распознавание голосовых команд на русском языке.
- Экранный аватар и голосовой ответ.
- Запуск приложений и открытие сайтов.
- Запоминание пользовательских сайтов и программ.
- Создание заметок и напоминаний.
- Случайное число и симуляция подбрасывания монеты.
- Локальная языковая модель через Ollama (если настроена).
- Облачный ИИ через API (если пользователь самостоятельно укажет ключ).
- Выбор браузера и других поддерживаемых провайдеров через настройки.

Набор доступных системных действий зависит от ОС. Не все возможности исходной Windows-версии доступны в Linux-порте.

## Установка в Linux

Поддерживаемые установщиком семейства дистрибутивов: Arch Linux (включая CachyOS и Manjaro), Fedora и Debian/Ubuntu.

Для Fish:

```fish
fish ./install.fish
fish ./run.fish
```

Для Bash:

```bash
chmod +x install.sh run.sh
./install.sh
./run.sh
```

Установщик устанавливает системные зависимости, создаёт локальное виртуальное окружение `.venv`, устанавливает Python-зависимости и при наличии архива распаковывает модель Vosk. Для установки нужны подключение к интернету и права администратора для пакетного менеджера.

Дополнительные функции Wayland/Hyprland могут требовать `wtype` и `hyprlock`. Эти инструменты не являются обязательными для запуска базового приложения.

## Настройки и пользовательские данные

При первом запуске Capri создаёт `config.json` с настройками по умолчанию. Этот файл предназначен для локального использования и не должен добавляться в Git: в нём могут находиться персональные настройки, пути к приложениям и API-ключи.

Журналы, напоминания и другие создаваемые приложением данные также относятся к локальному состоянию пользователя. Они не включены в исходный репозиторий.

Не публикуйте API-ключи и другие секреты. Для облачных провайдеров используйте собственный ключ и предусмотренные приложением настройки или переменные окружения.
